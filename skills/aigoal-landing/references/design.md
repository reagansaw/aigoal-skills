# 排版数字和品牌色

模板的 CSS 是在浏览器用 390×844（手机）和 1280×800（电脑）量出来的，**只有第 1 节的品牌色可以改**，其他不要动。

## 1. 换成你的品牌色

每个模板 `:root` 最上面有这几行，换成你的品牌就好：

| 变数 | 默认（玫红） | 用在哪 | 怎么换 |
|---|---|---|---|
| `--brand` | `#D03F58` | 主按钮底、强调字 | 你的主色 |
| `--brand-400` | `#DC4D65` | 首屏卡右上的亮光 | 主色调亮一点 |
| `--brand-500` | `#C94A60` | 渐层亮的那边 | 主色微微调亮 |
| `--brand-600` | `#B83349` | 首屏卡底色、米白底上的小字 | 主色调深一点（米白底上对比要 ≥ 4.5:1） |
| `--brand-700` | `#8E2438` | 渐层深的那边 | 再深一点 |
| `--brand-900` | `#3B0F18` | 顶条底色、「关于我们」卡底 | 很深、接近黑 |
| `--accent` | `#EFDFB3` | 首屏大字、顶条数字、勾勾圈 | 一个浅色，放在 `--brand-600` 上要看得清楚 |
| `--pill-bg` | `#F6E3E6` | 小标签底色 | 主色非常淡的版本 |

例：深蓝品牌 `--brand:#2F6FE0; --brand-400:#5B90EE; --brand-500:#3A78E6; --brand-600:#2459BC; --brand-700:#1A4290; --brand-900:#0D1F45; --accent:#FFE08A; --pill-bg:#E3ECFB;`

用户只给一个主色时：由你算出其他几个深浅，换好之后先截首屏给用户看。

底色、文字色（`--canvas`、`--surface`、`--ink`、`--muted`、`--line`）是暖白和深灰，大部分品牌都合，不用换。

## 3. 按钮

- `.btn`：inline-flex，min-height **56px**，padding 0 30px，圆角 **999px**，`700 17px/1`，字距 .04em
- 首屏上：白底，字 `--brand-600`，大一号 19px（`.btn-big`），手机宽 100%
- 其他地方：`--brand` 底白字

## 4. 间距 / 版面

- `section` 上下 **64px（手机）/ 96px（电脑）**
- `.wrap` 最宽 **1180px**，两边 20px（含 safe-area）
- 首屏卡外面 margin 12px 20px；卡里 padding 44px 20px（电脑 90px）
- 卡片圆角 22px，大卡 32px

## 5. 底部固定报名条（mbar）

- `position:fixed; bottom:0`，米白半透明 + `backdrop-filter: blur(10px)`，padding 10px 20px
- 上面一行小字（日期 / 「免费领取」说明），下面主按钮全宽
- `body { padding-bottom: 124px }` 免得盖到最后的内容
