# Seedance 2.0 提示词写法

AIGOAL 实测整理。写每一段提示词之前照这份对一遍。

## 能力与限制

- **一段 4–15 秒。** 超过 15 秒就拆成两段接力（或改用 Seedance 2.5，它一段可到 30 秒）。
- **会自己出声音**：台词、环境声、音效一起生成，嘴型对得上。
- **两种做法，一段只能选一种：**
  - **参考模式**：最多接 9 张图，提示词里用 `@image1`、`@image2` … 叫它们。要保人物、产品不走样时用。
  - **首帧模式**：一张图当第一格（可再加一张当最后一格），影片从这张图开始动。要锁死构图、锁死两个人的位置、做前后对比时用。
  - 在 studio.aigoal.ai 上，首帧和参考图不能同时接，同时接会被挡下来。即梦的「全能参考」入口里可以写「@图片1 作为首帧」再加别的参考；「首尾帧」入口不行。
- 叫法因平台而异：studio.aigoal.ai 用 `@image1`、`@video1`、`@audio1`；即梦用 `@图片1`、`@视频1`、`@音频1`（即梦不认英文叫法）。交付时照用户用的平台写；不知道就用 studio 的写法并提一句。
- **studio 各型号的规格**（2.0 / 2.5 / 2 Mini、档位、比例、上传格式）见 `studio-brain-snapshot.md`「规格」，有钥匙时以 `fetch_brain.py guide` 拿到的最新版为准。
- **即梦的素材上限**：图最多 9 张；视频最多 3 段、合计 2–15 秒、每段小于 50MB；音频最多 3 段、合计不超过 15 秒；全部加起来最多 12 个。studio 上 Seedance 2.0 Custom 最多接 9 张图，Seedance 2.5 更多（见 studio 的模型说明）。
- **提示词长度**：上限大约 2000 个字符，**目标控制在 1900 以内**，要真的数，不要估（实测估的常常少算一千多字）；搭画布的脚本会帮你数。经验值：每个镜头不超过 200 字，一段 15 秒不超过 800 字最稳，太长模型反而抓不住重点。
- **真人照片当参考**：即梦官方手册写明不支持写实真人脸部素材，会被拦截；studio 走 API，规则可能不同。用户本人出镜时，第一次一定先拿一段试；被拦的退路：①用图片模型把他做成一张高度相似的定妆照再当参考，②改用首帧模式，③只拍不露脸的部分（手、背影）。

## 公式

```
[总长 + 画幅 + 主体 + 核心动作] → [人物、场景的 @image 绑定] → 场景：… 灯光：…（整段的默认）→ [按秒分拍，每拍 6 要素] → 声音：环境声 + 按时间写台词 → [固定结尾：写实 + 不要]
```

每一段都照这个顺序写，学员拿到手一眼就知道哪一块管什么。

**每拍 6 要素**，跟 studio.aigoal.ai AI Workflow「做同款」用的是同一套，学员在 studio 和这个 skill 看到的结构一样：

`0–3s：主体 …｜动作 …｜场景 …｜光影 …｜运镜 …｜音效 …`

- 跟段首默认一样的要素就省略（场景、光影常常整段一样，写在段首一次就好），只写这一拍**变了**的。字数省下来留给动作和运镜。
- 台词不写在分拍里，统一放后面的「声音」那一块（真声绑定要逐句标，见「用真人的声音」）。

**固定结尾**：AI Workflow 搭图时会自动在每段补写实、不出字、动作、连戏这几条规则；这个 skill 写的提示词是直接贴进 Seedance 的，没有人帮你补，所以每段最后都要自己带上这段短版（约 150 字，别再加长，字数要留给画面）：

```
写实：真实实拍质感，皮肤看得到毛孔和自然光影，不要磨皮、美颜、塑料感或 CG 感。动作简单、一步一步做，一拍只有一个运镜。人物、道具、场景每拍都照上面的描述，不变脸、不换衣服。
不要：字幕、画面上任何字和数字、logo 变形、水印、多余手指、变脸、穿模。
```

「不要」后面可以再加这一段最容易错的一两条。

**开头 20–30 个字最值钱。** 模型靠开头锁主体，所以第一句就写：几秒 + 画幅 + 最有辨识度的主体 + 核心动作。

## 按秒分拍

```
0–3s：主体 …｜动作 …｜运镜 …｜音效 …
3–8s：切到…｜动作 …｜光影 …｜运镜 …
8–12s：……
```

一拍一个清楚的动作。原片在这一段里有几个镜头，就分几拍，并写明「切到」。每拍照 6 要素写，没变的要素省略。

- **生成秒数留余量**：AI 片段开头和结尾各约 0.5 秒最不稳（起手抖、收尾乱动），剪辑时要剪掉。所以一段生成的秒数 = 原片那几镜的长度 + 0.5–1 秒，取整数，最多 15 秒；第一拍从 0.5 秒左右才开始做事。
- **表情写成看得见的动作**：写「嘴角慢慢上扬、眼睛眯起来」，不写「很开心」。
- **动作拆成 3–5 步的顺序**：「伸手 → 拿起手机 → 翻过来 → 举到镜头前停住」，并写清楚左手还是右手。动作幅度越大越容易崩，能小就小。
- **反应要给时间**：吓一跳至少 1.2 秒、脸红至少 2.5 秒、哭至少 3 秒，太短模型做不出来。
- **一闪而过的东西**要写明秒数和「随即恢复」，例如「0.5 秒的闪白，随即恢复原画面」，不然它会做成两三秒。
- **人不要像雕像**：对话、凝视的画面写一句持续的小动作（呼吸起伏、眨眼、发丝微动、视线移动）；不想要的大动作才在「不要」里点名。
- **段落之间的衔接点**：每段最后一拍写清楚结尾停在什么画面、人物什么状态，下一段开头就从这个状态接。

（这一节的余量、反应时长、闪现和小动作几条，整理自 MapleShaw/seedance2.0-prompt-skill 的实测，MIT 授权。）

## 用原片当运镜参考（@video1）

最直接复刻运镜和节奏的方法：把原片那一小段剪出来当参考视频，提示词写：

```
运镜和节奏完全参考 @video1，不要复刻 @video1 里的人物、场景和文字。
```

- 剪法：一段 3–8 秒，里面只有一种运动（例如只有那个一镜到底的拉开），剪掉开头 1–2 秒的起手抖动。
- 适合：原片的运镜很难用文字描述清楚（复杂的一镜到底、环绕加升降、快速跟拍）。
- 风险：原片里有真人脸可能被拦；接了参考视频的生成通常比较贵；studio 上要接 `ref-video-1`，第一次先单段试。文字写得清楚的运镜，不用这招。
- 分镜板、多宫格图（包括我们的镜头条）拿来当参考时，一定要写「只参考构图和节奏，不要画出格子边框、编号和分隔线」。

## 贴原片模式（整段照 @video1 重拍）

上面那招只借运镜。这一招是整段照原片：镜头、构图、动作、节奏都跟 @video1，只换人物、产品或场景。用户在第 6 步选了「贴原片模式」才用。

**每段的提示词模板**（短就好，画面的事交给 @video1，文字只讲换什么）：

```
14秒，9:16竖屏。照 @video1 重拍：镜头、构图、动作、节奏完全照 @video1，一个镜头对一个镜头，不增不减。

换掉：
@video1 里的女生换成 @image1 的人物。@image1 是角色设定图，三格是同一个人，只参考人物，不要画出格子、分隔线和灰底。（外形一句，每段一字不差）
她手上的包换成 @image2 的包，大小和拿法照 @video1。

保留：其余的场景、灯光、道具位置、每个动作发生的时间点，照 @video1。

不要带进来：@video1 里的字幕、花字、贴纸、水印、logo，原来那个人的脸和发型。

声音：（三选一，见下）

写实：……（固定结尾，原文照抄）
不要：……（固定结尾，再加「多出 @video1 没有的镜头」）
```

- **分段**：一段 4–15 秒，切在镜头之间。参考视频一段 2–15 秒，一段只接一条。生成秒数 = 那段原片的长度往上取整，不加余量；多出来的不到 1 秒在剪辑表剪掉（「止」写原片那段的长度）。
- **换的东西要讲位置和大小**：「换成 @image2 的包」后面加「大小和拿法照 @video1」，不然产品会忽大忽小。
- **换场景**：写「场景换成 @image3，人物的位置、动作、镜头照 @video1」。场景跟原片差太多（室内换户外），动作会对不上地面和家具，先试一段。
- **原片有字幕**：字幕会被模型当成画面的一部分学进去。「不要带进来」一定写字幕；还带进来，就先在剪辑软件把原片字幕那一条裁掉或盖住，再切参考视频。
- **声音三选一**：
  - 保留原音轨：标题写「静音」，「声音」一行写「不生成声音」，粗剪用 `assemble.py --audio` 贴回原声。嘴型不保证对得上，对嘴要求高的口播不要用这个。
  - 模型生成：照「声音」的正常写法写环境声和台词。台词改过的只能用这个。
  - 完全静音：标题写「静音」，「声音」一行写「不生成声音」。
- **卡点、跳舞片**：切参考视频时加 `--keep-audio`，提示词加一句「动作的节拍照 @video1 的音乐」。最后还是贴回原声。
- **按秒的动作提要**（可选）：原片动作复杂、或第一次出片动作走样时，在「保留」下面补 2–4 行「0–3s 她把包举到脸旁边…」，帮模型抓重点。
- **风险和成本**：参考视频里有真人脸可能被审核拦；参考的秒数也算点数（参考秒数 + 生成秒数）；studio 上接 `ref-video-1`。第一次先只跑一段。
- **即梦**：叫法是 `@视频1`、`@图片1`。

## 段和段怎么接

1. **截上一段最后一格当下一段首帧**（首帧模式）：最稳，构图和人都接得上。
2. **视频延长**：把上一段当 @video1，写「将 @video1 延长 X 秒」，生成秒数填**新增**的秒数；开头写「接续上一段最后一格的构图和人物状态」，前 0.8–1.5 秒只做很小的动作，再开始新的事。
3. **独立生成再剪接**：场景本来就换了的段落用这个，靠剪辑和转场接。

## 音乐卡点

原片是卡点型（画面跟着节拍切）才需要：接一段音乐当 @audio1（或原片当 @video1），写「画面跟着 @audio1 的节拍切换，重拍时 … 」，并在分拍里写死哪一拍落在哪个动作上。一般剧情片的配乐还是放后制。

## @image 绑定：每一张都讲清楚拿来干嘛

| 用途 | 写法 |
|---|---|
| 人物 | `@image1 为人物参考，全片保持同一张脸、同一套衣服、同一个人` |
| 产品 | `@image2 为产品参考，外形、颜色、logo 位置保持一致` |
| 场景 | `场景参考 @image3` |
| 服装 | `穿 @image4 的衣服` |

- 只写「参考 @image1」不够，要写参考它的**什么**（脸？衣服？产品？构图？）。
- **编号每一段从 @image1 重新排**，只接那段用得到的图。全片用「图A、图B…」当图的名字，每段开头写「接图：@image1 = 图A，@image2 = 图C」。
- 提示词里提到的每个 `@imageN` 都要真的接了图，编号从 1 连着排。
- 只在一段里露面的配角不用参考图，写外形就好。主角、反复出现的场景才值得出一张图。
- 人物换衣服（小时候 / 长大、便服 / 制服）：绑定写「保持同一张脸」，不要写「同一套衣服」，衣服在那段另外写。

## 运镜：一拍只给一个主运镜

定镜 · 缓慢推近 · 缓慢拉远 · 横摇 · 直摇 · 跟拍 · 环绕 · 手持

- 用 缓慢 / 平稳 / 轻微 这种节奏词，别写技术参数。
- 运镜和人的动作**分开写**，不要搅在同一句。
- 同一拍别又「定镜」又「环绕」。
- 会动的运镜写清楚往哪里动、跟着谁、停在哪里。
- 人的动作越复杂，镜头越要稳。笑点、反转、反应落下的那一拍用定镜，让观众看清楚。

## 灯光：每一段都写

对画质影响最大的就是灯光。每段在分拍后面写一行「灯光：…」：光从哪来、冷还是暖、硬还是软（窗边自然光、黄昏逆光、柔和轮廓光、室内暖色顶灯、阴天漫射光 …）。段里某一拍换了光（开灯、走出室外），才在那一拍另外写。

## 质感

- 要真实：固定结尾的「写实」那句已经写了 `真实实拍质感，皮肤看得到毛孔和自然光影，不要磨皮、美颜、塑料感或 CG 感`，每段都带，不用另外写「质感」一行。
- 光写「真实皮肤纹理」不够，模型默认还是会给磨皮、美颜过的脸。一定要连「不要什么」一起写。
- 不要写「雀斑」「瑕疵」「不完美肌肤」，它会真的画一脸斑。
- 不要写 4K / 8K / masterpiece / best quality / ultra HD / 电影级，这些会让写实画面变塑料。（有些 skill 要求每段都加「4K超高清」，那是给 CG、奇幻大片用的；真人写实、UGC、口播一律不加。）
- **主角是动物（拟人猫狗）**：把「皮肤看得到毛孔」换成「真实的毛发质感，看得到一根根的毛和自然的光影明暗」，不然会长出人的皮肤。
- 要更像手机实拍，可以写来源型的小缺陷：轻微的平台压缩感、暗处一点噪点、白平衡略偏、手机广角的轻微变形。
- 手机随手拍风格：手持、自然手机画质、轻微晃动、不调色。

## 第一步：人物先做角色卡

出片前，每个人物先做一张 16:9 横版三格角色卡（纯灰背景：左格脸部特写、中格正面全身头抹掉、右格背面全身），选定了再当每一段的参考图。提示词模板、用照片做的写法、拟物角色、交付格式都在 **character-sheet** skill（`../character-sheet/SKILL.md`），照那里写；素材清单的名字写「人物A · 角色卡（横）」，画布脚本就出 16:9。

- **每段提示词接角色卡时加这一句**（不然会把格子、灰底画进影片）：`@image1 是角色设定图，三格是同一个人（左格定脸，中格定衣服，右格定背面），只参考人物，不要画出格子、分隔线和灰底。`
- **多人戏写演员调度**：每个人的站位、面部朝向、视线落在哪里（见快照「演员调度三要素」），不然视线和朝向会乱。

## 场景图要像实拍

Seedance 会照参考图的质感拍。场景图写得太干净，出来像渲染的室内设计效果图。

- 写成「一张像手机实拍的真实照片」，空景、没有人，加磨损、污渍、用过的东西、日常的灯光，再加「不要太干净，不要像渲染图 / 设计效果图」。
- 竖屏片的场景图名字写「（竖）」，脚本就出 9:16。

## logo 要怎么进画面

Seedance 自己画 logo 会变形，但 logo 可以先交给图片模型放进素材图，Seedance 只是照着拍：

- logo 上传当一张图（素材清单里叫「图L」）。
- **场景里的 logo**（招牌、布条、海报）：生成场景图时把图L 当输入（图生图），提示写「印着 @image1 的 logo，形状、颜色、字母照 @image1 一模一样」。这张场景图再当 Seedance 的场景参考。
- **要特写的 logo**（手机屏幕、包装）：用图生图做一张特写，输入人物图和图L，单独生成一段 4 秒的首帧模式插入镜头，剪进去。
- 出片后 logo 若还是变形，那几秒后制盖一张原图。后制贴 logo 一直都是保底做法。

## 台词的语言：一律写「马来西亚口语」

只写「马来语」「英文」「中文」，Seedance 会给印尼腔的马来语、美式英文、中国大陆腔的普通话（实测：只写「马来语口语」出来像印尼人讲话）。每一段「声音」那一块都照下面写，原句照抄，不要省：

| 用户要的语言 | 提示词里写这一句 |
|---|---|
| 马来文 | `台词讲马来西亚口语马来文（Bahasa Melayu pasar，吉隆坡口音），不是印尼语，不要印尼口音和印尼用词，都只讲一次。` |
| 英文 | `台词讲马来西亚口语英文（Manglish，带 lah、ah，马来西亚口音），不是美式或英式口音，都只讲一次。` |
| 中文 | `台词讲马来西亚口语中文（马来西亚华语，马来西亚口音），不是中国大陆或台湾的腔调，都只讲一次。` |

台词本身也要写成马来西亚人嘴巴讲的样子，光靠那一句不够：

- **马来文用马来西亚的词和口语拼法**：tak（不写 tidak / nggak）、nak（不写 mau）、boleh（不写 bisa）、kat（不写 di）、kereta（不写 mobil）、lesen（不写 SIM）、duit（不写 uang）、cakap（不写 ngomong）、macam mana（不写 gimana）、tengok（不写 lihat）；口语拼法 bawak、tido、kene、tau、dah、je、ni、tu；语气词 lah、weh、woi、kot。称呼用 sayang、awak、kau、abang，不用 kamu、lu、gue。
- **英文写 Manglish**：短句，带 lah、ah、meh、one、can / cannot（「Can drive or not?!」「Don't so angry lah.」），价钱讲 ringgit，不写美式俚语。
- **中文写马来西亚华语**：咯、啦、先、做么、几多钱、酱（这样）、很 sien，可以夹一两个英文或马来文词（「你做么会有我 best friend 的 WhatsApp？」），不用「啥」「咋」「儿化音」。
- **声音参考也要是马来西亚口音**：@audio 的录音是什么口音，出来就偏什么口音。最好用真的马来西亚人录 10–15 秒；用 studio AI Voice 生成样本时，样本的文字照上面的口语写，语言选 Malay（有这个选项的话），生成后先听一次像不像印尼腔，像就换一个声音。
- 用户没讲口音时，默认就是马来西亚口语；用户指定别的地方（新加坡、印尼、台湾）才改。

### 1. 念错字

- 字母缩写用连字号一个一个念：`L-R-T`、`K-L-C-C`。
- 数字写成嘴巴讲的样子：「八十八块」「四百五十千」「一百二十万」。英文台词也一样，写成马来西亚人讲的说法：RM2800 写「two thousand eight hundred」，不写「twenty-eight hundred」（那是美式说法）。
- 品牌名、公司名、人名靠写法救不了，同一种写法会一次对一次错。一定要念对的，就另外生成配音，或把这句留到后制配音，并在交付里提醒用户出片后先听这几句。
- 同一句台词全片只讲一次，写明「台词都只讲一次」。首尾呼应的金句也只生成一次，后制复用那一段。
- 台词放在分拍后面的「声音」那一块，按时间写：`0–7.5s 某某用（语气）的语气说：「…」`。每个说话的人都写语气。
- 没有画面主人的旁白不要叫 Seedance 生成，放后制配音。
- 同一个人跨段的声音会有点不一样。要连贯，每段都写一样的声音描述（年纪、口音、语气）；更讲究就后制统一配音。

## 用真人的声音（@audio1）

用户本人或代言人出镜时，接一段他的真声当声音参考，Seedance 会用这把声音讲新台词。

- **素材**：一段 10–15 秒的干净口播，没有配乐、没有别人的声音，开头结尾不要切在字中间。素材清单里叫「声A」，档案写 mp3。
- 每段开头在「接图」下面加一行：`接声音：@audio1 = 声A`。编号跟图一样，每段从 @audio1 排。
- 声音那一块第一句先绑定，**用衣着认人**：`@audio1 是女店主（@image1，穿白色衬衫、绑马尾的那位）的声音参考，她的每一句都用 @audio1 的声音讲；@audio1 只用来定音色，不要把这段录音当成背景声播出来。`
- **每一句她的台词都标上**：`女店主（穿白色衬衫）用 @audio1 的声音说：「…」`。不标的话，模型会把整段录音当背景音轨播出来。
- **同段的其他人要写明不用这把声音**：`小男孩用他自己的童声，绝不用 @audio1 的声音。` 不写的话常会变成两个人用同一把声音。
- 两个人都要真声：@audio1、@audio2 各绑一个人，每句都标，衣着要差很多，模型靠「看见的人」认声音，不靠编号。
- **录音和台词可以不同语言**：华语的真声拿来讲马来文、英文也行，只定音色，口音会带一点原本的味道。
- **这一段某人一句都不讲**：最好不要接他的声音；一定要接（为了跨段一致），就写「@audio1 这段不要播出来，他闭着嘴，没有口型」，不然整段录音会被当背景声放出来。

### 2. 画面里的字一定乱码

Seedance 写不出正确的字和数字，重生成也没用。

- 不叫它写任何字：店名、价钱、slogan、字幕、手机屏幕上的字都不要。
- 画面里只是顺带有招牌、手机、文件，就写「屏幕背对镜头 / 失焦 / 看不清文字」。
- 字幕、花字、价钱卡全部放后制。
- **要秀给观众看的屏幕（App、网站、logo）**：写「把手机屏幕正面朝向镜头举稳不动，屏幕是一片干净的白光」，不要写屏幕上有什么，「不要」里加「手机屏幕上出现任何图案或文字」。出片后把真的画面贴进那块白光，手机不动就只要贴一次。
- 要秀的是招牌、海报、包装上的字：那一镜用图片模型先出图，单独用首帧模式生成，或后制贴上去。

### 3. 不合物理

- 一拍只做一个简单动作。
- 难的接触动作（开门、握手、倒水、手拿小东西）用剪接跳过：不演「打开门」，直接切到「门已经开了」。
- 手尽量不碰产品，在旁边用手掌指着。
- 不写不限定的「快速」，写「缓慢」「平稳」。
- 接触动作跳不过、一定要拍的：那一拍只做这一件事，照「碰到 → 对方反应 → 结果 → 放开」四步写完。不要让人一直抓着、挡着，同时讲一长句台词。
- 情绪词后面要跟着看得到的样子：不只写「震惊」，写「瞳孔放大，往后退半步」。没讲话的那个人写明「闭着嘴听」。
- 反应要给够时间，不然会被跳过：吓一跳至少 1.2 秒，愣住或脸红 2.5 秒，哭 3 秒。
- **大动作会被改软**：「一脚踢开铁门」实测变成走进门。笑点靠这一下的，让它自己一拍、给 2 秒，写过程：「抬脚、门弹开、撞到墙」，再加音效「哐」。
- **小表情在近景、全景几乎看不到**：眨眼、挑眉、嘴角一扬是包袱的话，切到那个人的脸部特写，写「慢慢地眨一下左眼，停 1 秒」。

### 4. 两个人会乱

- 两个人外形要差很多：衣服颜色、发型、年纪。
- 位置写死：`@image1 的女人在画面左边，穿红色；@image2 的男人在右边，穿蓝色`。
- 不要让两个人交叉、换位、擦身而过。
- 能分开拍就分开：一镜一个人（正反打）比两人同框稳。原片的过肩镜头，前景那个人只露后脑和肩膀，写成「前景是一个背对镜头的失焦人影」就够了。
- 最稳：先用图片模型把两个人合成一张图，拿它当首帧。
- 三个人以上同框：不要写「镜头平移到第二位、第三位」，几张脸容易长成一样。改成定镜全景，用位置和衣服点名谁讲话；一拍只让一个人做大动作，其他人只做小反应。

### 5. 段和段之间变脸，或自己加东西

- 同一个人、同一件道具，**每一段都一字不差地把外形再写一遍**（年纪、发型、衣服、颜色、配件）。
- **模型会照刻板印象自己加东西**：中年女性专业人士常被加上眼镜，讲师加眼镜、老板加西装。提示词里不提也会加。防法：
  - 主角排在**第一张参考图**。排在后面、参考图又小（全身照里脸只占一点）的时候，模型最抓不牢。
  - **正面写出那个部位的样子**，例如「双眼直接露在外面，脸上只有口红」，不要写「没有戴眼镜」。
  - **用已经出片、确认像的那一格当第二张脸部参考**：第 1 段出片后，截一格脸清楚的特写，接给后面有她的每一段，写「@image1 定衣服和造型，@image2 定她的脸，脸照 @image2」。一段比一段稳。
- 要最连戏：上一段出片后，截它的最后一格当下一段的首帧。
- **产品颜色会跑**：参考图是白色洗衣机，片里出来灰色。产品的颜色、材质每一段都写一次（「白色滚筒洗衣机」），不要只靠参考图。
- **长得像的道具会变成同一样**：「衬衫、枕头套、车座套都雪白」实测三样都像白布。每样道具给一个只有它有的特征（车座套「有安全带孔、挂着车钥匙」），要观众看清楚的就拍特写。
- **最后一格可能是黑的**：每段多生成约 1 秒，后制头尾各剪 0.5 秒。

## 先生成一张定位图（两个人位置固定的戏）

两个人以上、位置从头到尾不变的戏（车里、餐桌两边、柜台里外、沙发、床边、讲台和台下），出片前先用图片模型生成一张**定位图**，再当这一段的参考图。只给角色卡和文字，模型每个镜头都要自己猜谁在哪一边，猜错就会换位、多画一样东西（实测：车里出现两个方向盘，重跑一次还是错；加了定位图一次就对）。

- **怎么做**：素材清单加一行「图D | 定位图 · <谁在做什么>（竖）| ⬜ | 第 N 段」，底下写 `- **图D**（输入：图A、图B、图C）：「…」`，输入是角色卡和空场景图。提示词写：一个能同时看到所有人的机位、每个人在画面的哪半边、手上在做什么、关键道具只有几个、在谁面前。
- **每段接自己的定位图**：位置换了（换座、换人站柜台里面）就再做一张。影片提示词里写「@image3 是这一段的定位图，谁在哪里、道具在哪里都照它」。
- **空场景图只拿来做定位图**，不要直接接到影片格：它里面的空座位、道具会被整张贴成背景。
- **先跑定位图再跑影片**：一张 1 点，看对了才花影片的点数。交付时把这个顺序讲清楚。

## 车里的戏（实测两次都错，照这四条写）

出过的错：画面里出现两个方向盘（一个她握着，一个在没人的驾驶座上）；司机双手抱胸没握方向盘；模型自己加了一个从后座往前拍的机位。原因都是提示词只讲了「车的左右」，又接了一张有方向盘的空车厢图。

1. **不要拿空车厢图当影片的场景参考**。空车厢图里有方向盘和空座位，模型会把它整张当背景贴上去，再另外画一个握方向盘的人，就变成两个方向盘。改成先用图片模型做一张**定位图**：从车头外隔着挡风玻璃往里拍，两个人已经坐好，谁握方向盘一眼看得出来（输入：两张角色卡 + 空车厢图）。一张 1 点，先看对了才跑影片。谁开车换了（换座），就再做一张，每段接自己那一张。
2. **位置写「画面的左右」，不写「车的左右」**。右舵车从车头往里拍，司机在画面**左半边**；写「他坐右边驾驶座」模型分不清是车的右还是画面的右。每个机位第一次出现时写清楚：「车头外隔着挡风玻璃拍，她在画面左半边握着方向盘，他在画面右半边副驾，面前只有仪表台」。
3. **机位编号，最多三个，都在车头外或贴着脸**。写「机位一 / 机位二」，后面的拍子直接写「机位一」，不要写「构图同第一拍」（模型会自己换一个角度）。不用从后座往前拍、从副驾拍司机侧面这类要重新摆方向盘的角度。
4. **每段都写这三句**：「全车只有一个方向盘」「司机双手每一拍都握着方向盘」「副驾面前只有仪表台、没有方向盘」；「不要」里加「两个方向盘、没有人的驾驶座、没握方向盘的司机、从后座往前拍的机位」。两人之间的互动（拍手臂）改成拍肩膀或只做手势，不要让司机的手离开方向盘伸过去。

## 结尾的「不要」

基本款：

```
不要：画面出现任何文字、字幕、logo、水印；人脸变形、多出手指、手部变形、物体穿过身体；
中途换人、换衣服、换场景。
```

出片有问题时，只重写出问题的那一段，先看是不是一拍塞了太多动作或台词。不要靠一直加长「不要」清单来盖：清单越长，真正要拍的动作越容易被挤掉。

再按这一段最容易出错的地方加一两条，不要每段贴一样的：两人正反打加「两个人的正脸同时出现在一个画面里」；有桌子、手枕加「手穿过桌子」；配角不露脸加「某某露出正脸」；秀屏幕加「手机屏幕上出现任何图案或文字」。
