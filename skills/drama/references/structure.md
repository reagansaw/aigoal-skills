## 1. 两种长度

| | 短梗 | 大片 |
|---|---|---|
| 成片 | 20–30 秒 | 90–135 秒 |
| 场景 | 1 个 | 2–4 个 |
| 有名字的人物 | 最多 3 个 | 最多 5 个 |
| 台词 | 3–6 句，全片不超过 80 字 | 多数 25–50 句，全片字数不超过「秒数 × 3.5」 |
| 反转 | 1 次，结尾能加第二下更好（一句话或一个眼神） | 2 次 |
| 产品出现 | 最后 8–10 秒：产品约 5 秒（一句旁白或只放后制字卡，字卡可以叠在人物定格的画面上），之后回到人物 3–5 秒，最好是第二下。第 7 节的「两到四句」是大片的写法 | 全片的 70–80% |
| 适合 | 第一次做、要多拍几支测试、预算少 | 账号的主打片、要人追着看 |

句数和字数都是上限，不是要凑满的数。后制配音的句子也算进去。没有名字的配角不算人数。

人物和场景要少，有两个原因：观众记不住，AI 也拍不稳（人一多，脸和衣服就会变）。

写剧本时就避开 AI 最容易拍坏的三样，后面会省很多重跑：

- **一个画面里超过三个人都要有戏。** 多人同框时，只让一个人做大动作，其他人做小反应。
- **人和东西的复杂接触。** 举杯、递东西、抓住衣领这类动作最容易变形。能用「东西已经在手上」开始，就不要拍「拿起来」的过程；一定要拍接触，那一行只做这一件事。
- **一边做复杂动作一边讲长台词。** 拆开：先做完，再讲。

## 2. 短梗的三种骨架

### A. 一句话的后果

一句平常的话，被人（或神、或机器）照着另一个意思办了。当事人到最后都不明白。

| 拍 | 秒数 | 做什么 |
|---|---|---|
| 1 | 0–4 | 一个人做一件每天都做的事，讲出那句话 |
| 2 | 4–10 | 后果发生。他愣住 |
| 3 | 10–20 | 旁边的人看到了，学他讲，后果一个比一个大（两到三次） |
| 4 | 20–28 | 当事人看着这一切，讲一句最老实的话。「我只是要面包啊。」 |
| 后制 | +2 | 字卡：品牌 + 一句话 |

片里一个字都不解释。最后一句是当事人在问，留言区的人会替他答。

### B. 三次升级

同一件事发生三次，一次比一次惨，第三次接产品。

| 拍 | 秒数 | 做什么 |
|---|---|---|
| 1 | 0–3 | 第一句就是冲突（钱不够、时间不够、来不及） |
| 2 | 3–10 | 放弃第一样，画面上立刻垮一级 |
| 3 | 10–17 | 放弃第二样，垮到很惨 |
| 4 | 17–25 | 旁边的人看不下去，一句话给出产品 |
| 5 | 25–30 | 恢复原状，比原来更好 |

### C. 认真的开场，一句老实的回答

开场像电影（劫案、新闻、审问、丧礼），演到最紧张，有人问一句「为什么」，回答的人很老实地讲出原因，那个原因就是卖点。

| 拍 | 秒数 | 做什么 |
|---|---|---|
| 1 | 0–5 | 开场世界，第一秒就有画面 |
| 2 | 5–12 | 推到最紧张 |
| 3 | 12–17 | 一句问题 |
| 4 | 17–22 | 一句老实的回答 |
| 5 | 22–30 | 证明画面：一个会被截图、一眼看懂卖点的画面 |

## 3. 大片的段落表

以 100 秒为例，其他长度照比例。

| 段 | 位置 | 做什么 |
|---|---|---|
| 钩子 | 0–3 秒 | 第一个画面是人，第一句是冲突台词，不超过 12 个字。不放旁白、天气、空镜 |
| 压 | 3–25 秒 | 类型壳的开场戏：谁压谁、当着谁、拿走什么（见 `genres.md` 第 4 节）。埋第一条线索 |
| 推高 | 25–40 秒 | 事情变得更糟，而且有期限（撑不到今晚、明天就要搬）。让一个人替观众问「怎么办」 |
| 第一次反转 | 40–55 秒 | 类型里观众在等的那一下来了：有人登门、遗嘱打开、「你知道他是谁吗」 |
| 吊到最高 | 55–65 秒 | 让所有人（和观众）都相信答案很大。手提箱慢慢打开、全家下跪 |
| 落空 | 65–70 秒 | 答案出来，是一样很小、很日常的东西。全场安静一秒 |
| 成立 | 70–78 秒 | 那样小东西真的有用。事情真的发生了，不靠人讲。骂过他的人当场变脸 |
| 第二次反转 | 78–82 秒 | 产品出现。一句最短的问题引出来：「这个什么来的？」 |
| 产品 | 82–94 秒 | 12–16 秒，两到四句卖点（见第 7 节） |
| 收尾 | 最后 5–8 秒 | 回到人物，回扣开场，最后再笑一次（见第 8 节） |

两点说明：

- 「落空」和「成立」之间只隔几秒，但一定要分开。先让观众「什么？」，再让他「哦——」。
- 如果用的是「两样合成一样」那种机制，揭晓的那一下本身就是产品，第一次和第二次反转会合在一起。那就把「吊到最高」拉长，让医生、护士一个一个吞吞吐吐。

## 4. 「观众以为什么」表

写大片之前先填这张表。它逼你站在观众那边，一段一段确认：他这一刻相信的是什么，有没有被你带着走。

例（冷气，卖点：保修五年，时间到了师傅自己上门）：

| 位置 | 发生什么 | 观众以为 |
|---|---|---|
| 0–3 秒 | 雨夜豪宅，老爷盯着大门的监视器，茶杯在抖。「五年了……他真的回来了。」 | 仇家找上门 |
| 3–25 秒 | 太太在收金饰，儿子要报警。闪回：五年前老爷把一个年轻人推出大门，年轻人回头讲「五年后，我一定回来」 | 当年被赶走的穷小子发达了，回来报仇 |
| 25–40 秒 | 女儿化好妆下楼：「他是回来找我的。」老爷叫人备茶、备红包 | 是被拆散的情人，回来娶她 |
| 40–55 秒 | 门铃响。门开，逆光，一个男人撑着黑伞，身后两盏车头灯 | 来了，要跪了 |
| 55–65 秒 | 老爷带着全家跪成一排：「当年是我有眼不识泰山！」 | 他会讲出自己现在是谁 |
| 65–70 秒 | 男人一脸懵，抬头看了一眼天花板：「老板，五年到了。我来洗冷气的。」 | 什么？ |
| 70–78 秒 | 女儿：「你不是回来娶我的？」男人：「小姐，你是谁咧？」闪回补完：当年他是来装冷气的，一直交代五年要保养，老爷嫌他啰嗦把他赶出去 | 哦——原来是这样 |
| 78–82 秒 | 老爷：「你做么酱准时？」男人指了一下冷气机上的贴纸 | 是广告！ |
| 82–94 秒 | 产品段 | |
| 最后 6 秒 | 男人收好工具走到门口，回头：「老板，下次是十年后。」全家又抖了一下 | 最后再笑一次 |

为什么链：保修五年、到期上门 → 准时到五年后同一天出现在门口 → 谁会把五年前的一句话记到今天？只有仇家 → 老爷为什么怕？他这一世赶走过太多人，不记得是哪一个 → 开场是雨夜的「他回来了」。

表里「观众以为」那一栏，每一格都应该是错的，直到「落空」之后才对。有一格观众已经猜到答案，那一段就露底了，回去改。

## 5. 反转要改变一个人

每一次反转填这五格：

| 观众以为 | 主角以为 | 对手以为 | 真实情况 | 揭晓后谁变了 |
|---|---|---|---|---|

- 最后一格不能空。反转之后一定有人的态度或行动变了（老爷从骂人变成下跪）。没有人变，那只是一个新消息，不是反转。
- 第二次要比第一次大一级。第一次改变一家人，第二次改变整件事的性质（原来这是一支广告）。
- 主角自己可以从头到尾什么都不知道。「他不知道自己很厉害」比「他一直在装」好笑。

## 6. 线索：埋三条，不讲破

答案不能讲，但要让回头再看的观众发现「原来早就讲了」。埋三条：

- 一样**东西**：闪回里，年轻人被推出门时背着一个长长的袋。观众以为是行李，其实是工具袋。
- 一句**骂人的话**：老爷当年骂他「啰嗦！五年五年，讲了八百次！」
- 一个**旁人的误会**：女儿讲「他当年每次来，都一直抬头看我的房间。」他看的是冷气机。

三条都要是戏里的人自然会讲、会做的。专门讲给观众听的，就是讲破。

**不讲破的规矩**：揭晓之前，没有一个人把答案讲出来；揭晓之后，也没有人解释为什么好笑。女佣在第 30 秒讲一句「老爷，他就是当年来装冷气的那个师傅啊」，整支片就死了。观众只看到全家下跪、他抬头看天花板，自己想通。真的需要讲明的，留到产品那一段由旁白讲。

## 7. 产品那一段

- 用一句最短的问题引出来，问的人是戏里的人：「这个什么来的？」「你到底擦了什么？」
- 两到四句，每句 4–10 个字，大白话。
- 第一句讲那件「每次都这样」的事，后面才讲产品怎么解决。「冷气不冷了，才想起要洗。全马来西亚的人都酱。」
- 只讲用户给的那一个卖点。数字用用户做得到的，没有就写 `【填：…】`。不编功效、销量、评价。
- 这是全片唯一可以把话讲明的地方。
- 带品牌名的句子标 `【后制配音】`：AI 影片念品牌名经常念错，这几句要另外配音。画面里的字（价钱、品牌、新闻字条）也一律标 `【后制字卡】`。

## 8. 收尾

产品段之后一定回到人物，不要停在产品上。三种收法，挑一种：

- **回扣开场那句话。** 开场骂人的那句，结尾原句奉还，或反过来讲。当年老爷骂「啰嗦！」，结尾他追到门口：「师傅！你再啰嗦多几句啦！」
- **回扣开场的损失。** 开场撞出来的裂痕，结尾被当成极品。
- **再来一次。** 同一件事又要发生了：「老板，下次是十年后。」全家又抖了一下。

最后可以留一个留言钩子（片尾问一句观众答得出来的话），放在后制字卡，不放进台词。

## 9. 时长预算

拿一支做好的 AI 成片的字幕量过：华语台词平常大约每秒 4 个字，吵架、大喊的时候最快到 6 个。剧本上写「2 秒讲 17 个字」，出片时它会自己拖成三四秒，后面的台词就被挤掉或切掉。

算字：一个汉字算 1，一个英文词或一个数字算 2，标点不算。

- **每一行**：字数 ÷ 秒数，4 左右最舒服，超过 5 很赶，超过 6 一定讲不完。12 个字的台词，那一行至少给 3 秒。
- **第一句**：不超过 12 个字，3 秒内要讲完。
- **全片**：大片的总字数不超过「秒数 × 3.5」，因为有些镜头没有台词。100 秒的片，350 字已经是满的。
- **没有台词的镜头也要算秒数**：

  | 这一行在做什么 | 最少给几秒 |
  |---|---|
  | 简单动作（转头、放下杯、开门） | 2–3 |
  | 中等动作（站起来走过去、把东西排在桌上） | 3–5 |
  | 复杂动作（多人一起动、追、摔） | 5–8，超过 8 秒就拆成两行 |
  | 吓一跳 | 1.2 |
  | 脸红、愣住、慢慢明白过来 | 2.5 |
  | 哭 | 3 |
  | 情绪特写（要观众看清他的脸） | 4 |

- **一行的秒数取大的那个，不是加起来**：这一行有台词也有动作，就看台词要几秒、动作要几秒，取比较长的。
- **什么时候拆成两行**：写出「先……然后……接着」，而且中间有人换了位置、换了朝向、手上的东西变了、或情绪变了，就拆。
- **反应要给时间**：笑点和反转之后的那一下反应，是全片最不能省的。AI 影片里时间给不够的反应会被直接跳过。
- 超了就删句子，不要把秒数写小。

有 Python 就跑一次 `scripts/check_script.py <剧本.md>`，它会把每一行算给你，顺便找出书面词和语气词的问题。没有 Python 就照上面手算。

写完在剧本下面列统计：句数、总字数、每秒几个字、产品在第几秒（占全片几成）。

## 10. `剧本.md` 的样子

```markdown

## 一句话
（一句会被人转述的话）

## 为什么链
卖点 → … → … → … → 开场

## 人物
| 人物 | 是谁 | 讲哪一种话 |

## 场景
1. …

## 观众以为什么（大片才要）

## 逐句剧本
| 秒数 | 画面 | 台词 |
|---|---|---|
| 0–3 | （一行只写一个主要动作，写看得见、听得到的） | 老爷：「……」 |

- 【口语待确认】…
- 【填：…】…

## 后制清单
```
