# 台词：写成嘴巴讲的

台词是给演员（或 AI 配音）念的，观众只听一次。纸上顺、嘴里拗，就是错的。

AI 写台词有两个固定的毛病：写得像中国的短剧，和写得太工整、把意思讲得太满。这一份就是改这两样。

## 1. 先定每个人讲哪一种话

同一支片里，不是每个人都讲一样的话。先给每个角色定一档，写的时候不要混：

| 档 | 谁 | 怎么讲 |
|---|---|---|
| 街坊口语 | Uncle、Aunty、小贩、师傅、邻居 | 短句，掺方言词和马来词，语气词多 |
| 年轻人口语 | 学生、上班族、情侣 | 短句，掺英文词（confirm、sure、on 不 on），语气词有但少一点 |
| 正式 | 主播、律师、医生宣布病情、黑西装、法官、旁白 | 标准华语，一个语气词都不加 |
| 戏腔 | 豪门老爷、武侠人物、宫廷 | 文绉绉、四字词，故意端着 |

**反差就是笑点**：正式的人和戏腔的人越端着，旁边那句街坊口语越好笑。所以不要把全部人都改成「啦、咯」。主播讲「全国水坝的水位，跌破十巴仙」，下一句女儿讲「爸，你想办法啦」，两句都对。

马来人、印度人角色讲的是他们平时真的会讲的话：马来话短句、英文短句、或简单的华语单词。不要让他们讲流利的书面华语，也不要拿口音当笑点。

地区差别：巴生谷、怡保多掺广东话词，槟城和北马多掺福建话词，新山靠近新加坡。用户讲了地区才往那边靠；没讲就用全马都听得懂的。

用户要掺方言时，一支短梗掺一两个词就够，掺在街坊档的角色身上：

- 广东话：好彩（幸好）、搞掂（办好了）、得闲（有空）、几多钱、靓仔、靓女、顶不顺（受不了）、死咯
- 福建话：好料（好东西）、吃饱没、kam siah（谢谢）、bo jio、paiseh

方言字 AI 配音常常念错，掺了方言的那一句标 `【后制配音】`，并列进「请你确认」。

## 2. 换词表：中国讲法 → 大马讲法

写完整份台词，对着这张表扫一次。

| 中国讲法 | 大马讲法 |
|---|---|
| 说 | 讲（你讲什么、讲话啦） |
| 这样、这么 | 酱（不要酱啦、酱多人） |
| 为什么、干嘛 | 做么（你做么不关冷气） |
| 而已 | 罢了（剩一口罢了、才刚拖好罢了） |
| 不知道 | 不懂（我不懂咧）；问人用「懂不懂」 |
| 百分之十 | 十巴仙 |
| 一万、三万、十万 | 十千、三十千、一百千（年轻人讲 30k） |
| 元、块钱 | 令吉、块（讲出口多数是「块」，字卡写 RM） |
| 空调 | 冷气 |
| 停水、限水 | 制水 |
| 洗澡 | 冲凉 |
| 脏 | 肮脏 |
| 房子 | 屋子、屋（一间屋） |
| 小区 | 花园、condo |
| 首付、月供 | 首期、供屋、供车 |
| 上班、下班 | 做工、放工 |
| 发工资 | 出粮 |
| 请假 | 拿假 |
| 出租车、打车 | 德士、叫 Grab |
| 公交车 | 巴士 |
| 摩托车、自行车、卡车 | 摩多、脚车、罗里 |
| 停车 | 泊车、parking |
| 堵车 | 塞车 |
| 驾照、罚单 | 礼申、saman（中 saman） |
| 菜市场、夜市 | 巴刹、pasar malam |
| 外卖打包 | 打包、tapau |
| 饮料 | 水（叫水、喝什么水） |
| 结账 | 还钱、算钱 |
| 零钱 | 散钱 |
| 旅游 | 吃风 |
| 高利贷 | 阿窿、大耳窿 |
| 周一到周五 | 拜一到拜五 |
| 大爷、大妈、小伙子 | Uncle、Aunty、年轻人 |
| 一个榴莲、一个球 | 一粒榴莲、一粒球 |
| 一家店、一套房 | 一间店、一间屋 |

叫人：茶室和档口叫「老板」或「Boss」；不认识的长辈一律 Uncle、Aunty。

全马都懂的掺杂词（可以用，一支片三四个就够）：paiseh（不好意思）、tapau、kacau（搞乱、烦）、tahan（顶住）、cincai（随便）、sien（闷、烦）、syok（爽）、jialat（惨了）、bo jio（没约我）、kantoi（被抓包）、gostan（倒车、反悔）、pokai（没钱了）、Haiya、Aiyo、Walao。

**不确定的词不要硬塞。** 用错一个口语词，比不用更假。拿不准的，照标准华语写，在剧本下面列出来请用户确认。

## 3. 语气词：一句一个，放对位置

| 词 | 什么时候用 | 例 |
|---|---|---|
| 啦 | 催、劝、理所当然 | 讲啦！／不要酱啦 |
| 咯 | 无奈、事情就是这样 | 我刚刚赶他出去了咯 |
| 咧 | 追问、还没、带一点不服 | 他是谁咧？／面还没泡好咧 |
| 嘛 | 这还用讲 | 车很肮脏了嘛 |
| 咩 | 怀疑地反问 | 你不是讲不要叫你爸咩？ |
| 啊 | 质问、确认 | 你有问题啊？ |
| hor | 要对方点头 | 很贵 hor |

规矩：

- 一句最多一个语气词。
- 连续三句里至少有一句不带。每句都带，就是硬装口语。
- 正式档和戏腔档的角色不带。
- 语气词跟着情绪走，不是跟着角色走。同一个人生气时讲「滚！」，求人时才讲「不要酱啦」。

## 4. 大马华语的句式

- **先** 放句尾：等下先、我吃了先、你听我讲先。
- **有 + 动词**：我有认识一个人、我有去过、你有听到吗。
- **……来的**：这个什么来的？他是谁来的？
- **……到**：痛到不行、贵到要命、热到全身湿。
- **才刚……罢了，就……**：才刚拖好地罢了，就有人踩。
- **一样都……**：一样都不会、一样都没有。
- **中**（遇到倒霉事）：全马来西亚的人都中过。
- **给**（被）：给他骂、给人骗。

## 5. 每一句台词都在做一件事

人讲话是为了让对方做点什么：逼他、求他、试探他、推开他、保住自己的面子。下笔前先问「这一句是要对方怎样」，答不出来的句子多数可以删。

- 两个人都知道的事，不会为了观众再讲一遍。「我们结婚十二年了」是讲给观众听的；老爷骂「十二年了！除了吃，你还会做什么？」是在逼人，观众顺便知道了十二年。
- 可以答非所问，可以讲一半。全家等他求情，他只问「那个饭盒，我可以拿走吗？」。
- 不替作者讲主题，不替观众讲答案（见 SKILL.md 的「不讲破」）。
- 不同人的声音，来自身份、关系和眼下的压力，不靠固定口头禅。把「啦」换掉人物就没分别，那是标签，不是声音。

## 6. AI 味清单

写完对着查，中了就改：

| 毛病 | 样子 | 怎么改 |
|---|---|---|
| 翻案腔 | 「不是……而是……」「你以为……其实……」 | 直接讲后半句 |
| 三连排比 | 「没有钱、没有屋、没有未来」 | 留一个最痛的 |
| 名词化 | 「对你进行了隐瞒」 | 「我骗了你」 |
| 连词太多 | 因为、所以、但是、同时 | 口语很少用连词，删一半 |
| 动作后面补情绪 | 他摔门。「我真的很生气！」 | 摔门就够了 |
| 金句收尾 | 每一场最后一句都像海报字 | 让人物讲一句平常话，或干脆不讲 |
| 太齐 | 每句一样长、一人一句轮流 | 让一个人连讲两句，让一个人不回答 |
| 书面双音词 | 购买、使用、进行、非常、立刻 | 买、用、做、很、马上 |
| 假细节 | 凌晨三点、第三根烟 | 换成这门生意真的有的数字 |
| 介绍设定 | 「身为这个家的长子，我……」 | 删掉，用别人怎么对他来交代 |

## 7. 对照例子

| 书面（AI 常写的） | 嘴巴讲的 |
|---|---|
| 父亲，请您想想办法吧！ | 爸，你想办法啦！ |
| 全国都在限水，你居然还用水浇花？你是不是有毛病？ | 全国在制水，你还拿水去浇花？你有问题啊？！ |
| 这十二年来，你除了吃饭之外什么都不会。 | 十二年了！除了吃，你还会做什么？一样都不会！ |
| 请稍等一下，我的泡面还没有泡好。 | 等下先啦，我的面还没泡好咧。 |
| 他到底是什么人？ | 他……他到底是谁来的？ |
| 你为什么不把空调关掉呢？ | 你做么不关掉冷气？ |
| 这次又白排了。 | Haiya……又白白排队了啦。 |
| 刚拖完地就有人踩，每个马来西亚人都经历过。 | 才刚拖好地罢了，就有人踩。全马来西亚的人都中过。 |
| 这套房子首付只要三万。 | 这间屋首期三十千罢了。 |
| 对不起，是我误会你了。 | Paiseh 啦，是我看错你。 |

## 8. 写完怎么查

1. **读出声。** 一口气讲不完的拆开。绕口的改。
2. **扫换词表。** 第 2 节的左栏有没有漏掉的。
3. **数语气词。** 有没有一句两个、有没有连续三句都带、正式角色有没有带。
4. **查 AI 味清单。**
5. **冷读一次。** 假装第一次看：哪一句是讲给观众听的？哪一句换一支片也能照搬？删掉最后一句试试，戏有没有更好。

## 9. 用户是最后一关

大马人讲话每个地方、每个年纪都不一样，你写的只能到八成。交剧本时：

- 把你拿不准的词列出来（`【口语待确认】`），请用户确认。
- 请用户随手改三句。他改了，就照他改的口气把其余的台词再顺一遍，不要只改那三句。
