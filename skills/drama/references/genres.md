# 类型壳：借一种观众两秒就认得的戏

开场借一种大家看过一百次的戏，观众两秒就知道「哦，是这种」，然后就会等那种戏里一定会发生的事。我们要做的是：照足规矩演，在观众等的那一下拐弯。

一支片只借一个壳。堆两三个，观众就认不出来了。

## 1. 狗血短剧的壳

| 壳 | 观众两秒认得的画面 | 观众在等的那一下 | 拐弯的地方 |
|---|---|---|---|
| 豪门逼婚、要继承人 | 大宅大厅，长辈指着晚辈的鼻子 | 孩子出世、身世揭晓 | 生出来的是产品 |
| 赘婿被赶 | 寿宴或饭桌上，全家骂上门女婿是废物，逼他签离婚书 | 大人物登门找他，全家跪下 | 他的「身份」是一样很普通的本事 |
| 战神归来 | 穿着外卖制服或保安制服的人，在同学会被羞辱 | 他打一通电话，来了一队人 | 来的那队人，是来做一件很小的事 |
| 霸总 | 黑西装、落地窗、秘书排成一排 | 「我要这间公司明天消失」 | 他的命令很小、很生活 |
| 重生 | 上一世惨死的闪回，睁开眼回到某一天 | 这一世他抢先一步 | 他重生回来只为了改一件很小的事（上一世买错了东西） |
| 真假千金 | 豪门认亲，真女儿穿得很寒酸，假女儿在旁边装可怜 | 拿出证据，当场拆穿 | 证据是产品留下的痕迹 |
| 王牌离职 | 被老板当众羞辱的员工，放下辞职信 | 客户全部跟着走，老板上门求他 | 客户跟的不是他，是他用的那样东西 |
| 神医、穿越 | 现代人穿到古代，古人束手无策 | 拿出现代的东西，全场看呆 | 古人把那样东西认成别的（神兽、护心镜） |
| 虐恋重逢 | 雨里，「三年了，你还回来做什么」 | 误会解开 | 他当年走的原因荒谬但讲得通 |
| 捉奸 | 丈夫带着亲戚踢开酒店房门 | 「他是谁！」 | 被子底下的不是人 |
| 争家产 | 律师宣读遗嘱，几房人各怀鬼胎 | 全部留给一个没人认识的名字 | 那个人是做某一行的师傅 |

## 2. 电影和电视的壳

| 壳 | 认得的画面 | 在等的那一下 |
|---|---|---|
| 鬼片 | 深夜、长发白衣、全村关门（本地观众认得 Pontianak） | 鬼扑上来 |
| 灾难片 | 新闻快报、指挥中心、「全国」两个字 | 有人站出来 |
| 警匪、特警、审问 | 警车包围、谈判专家拿喇叭、审问室一盏灯 | 嫌犯开口 |

| 体育转播 | 两个评述员、慢动作重播、评分牌 | 「十分！」 |
| 武侠、宫廷 | 擂台、皇帝发怒、「拖出去」 | 高手出招 |

| 丧礼、婚礼 | 灵堂、哭声；或新郎不见了 | 有人讲出不该讲的话 |

## 3. 大马本地的场面

把壳搬到这些地方，本地观众会觉得「这是在讲我」。场面要是剧情的一部分，不是布景：故事有一步必须因为这个地方才成立。

- 茶室早上：固定的桌、叫水、报纸、旁边的拿督公神龛
- 嘛嘛档半夜：一群不同种族的人挤着看球
- 新年 open house：门口一堆拖鞋、坐着不走的客人
- 榴莲档、pasar malam、巴刹
- 塞车、找 parking、过路费、长堤
- 屋子的大门铁花、车廊洗车、排屋的邻居隔着篱笆讲话
- 学校假期、放榜、补习
- 雨季、制水、停电、太热

三样不碰：种族、宗教、王室。也不碰政党和选举。神明只出现神龛、香火这些象征，不拍脸、不让他出丑。

## 4. 十秒内让观众站到弱者那边

狗血剧的开场都在做同一件事：让一个人当众被压到最低。四样凑齐，十秒就够：

1. **公开场合**：饭桌、寿宴、公司、大厅，有人在看。
2. **一句定罪**：「十二年了，你除了吃，还会做什么？」不解释前因，直接骂。
3. **最该帮他的人不帮**：老婆低头、妈妈转身。
4. **当场拿走一样东西**：甩离婚书、收钥匙、赶出门。

写第一场之前，先把这五样填出来：地点、动作、谁压谁、谁在旁边看、一样会被记住的东西（饭盒、离婚书、手提箱）。

骂人的那个要有筹码（他是老板、是一家之主、手上有证据），不能只是坏。

## 5. 身份揭晓和打脸：怎样才爽

戏仿也要照足规矩，观众才会上当。

- **压到最低才揭。** 揭晓放在欺负人的那个最嚣张的时候，不要早。
- **别人来证明，不是自己讲。** 大人物登门、一队人鞠躬，比他自己讲「其实我是……」有力十倍。
- **要打在当初骂他的人脸上。** 骂过他的人必须在场，而且要看到那个人从嚣张到害怕到讨好。
- **第一次露一点，要被人当成碰巧。** 这样后面才有第二次反转的位置。
- **靠结果，不靠嘴。** 让事情真的发生（门打不开了、客户全走了、全村的蚊子不见了），不要让角色解释他有多厉害。产品就是那个结果。
- **干脆。** 揭晓之后不要拖，一两句就收。

四种垮法：揭得太早、没有卡在情绪最高的地方、打脸跟感情没有关系（只是炫富）、揭完拖泥带水。

## 6. 怎么选

- 先看机制，再配壳。机制是「大家等的答案是一样很小的东西」，就配身份揭晓类的壳；机制是「只有他没事」，就配鬼片、灾难片。
- 壳和产品离得越远越好。卖冷气不要从冷气店开场。
- 同一个行业给几个人写，每人用不同的壳。
- 壳里的人要认真。豪门就要真的像豪门，鬼片就要真的吓人。好笑来自「这么认真地演这么荒谬的事」，演员一挤眉弄眼就完了。
