# 系列：让人看完这一集，想看下一集

单集是直接广告，产品是故事的答案。系列是另一回事：固定两三个角色，8 到 10 集，每集 30–60 秒，免费发，产品植入在里面。系列卖的不是这一集，是「下一集」。

## 目录

1. 先定四样东西
2. 十集怎么排
3. 一集里面怎么走
4. 集尾钩子十三种
5. 开头怎么接上一集
6. 哪些东西不能一集还完
7. 产品怎么植入
8. 追更失败的病
9. 交付：系列表和第一集

## 1. 先定四样东西

写任何一集之前，先定这四样，写在系列表最上面：

| 定什么 | 例（防骗系列） |
|---|---|
| **一个人要什么** | 阿珍想把被骗走的三万块拿回来 |
| **谁在挡他** | 一个从来不露脸的「投资老师」 |
| **观众每一集回来看什么**（一句话） | 她这次会不会又上当 |
| **最后一集停在哪里** | 她在茶室拦住另一个正要转账的 Aunty |

第三样最重要。答不出「观众每一集回来看什么」，就还不是系列，只是十支不相干的片。

人物最多三个有名字的，全系列同一张脸、同一套衣服、同一种讲话方式。只有声音、不露脸的对手也算一个。没有名字的配角可以在几集里重复出现，每一集最多讲一句。场景三四个，重复用。这样观众认得人，AI 也拍得稳。

再定两样，系列才会有味道：

- **主角不能是笨的人。** 观众看到笨人被骗、被欺负，只会想「我才不会」。主角要是大家以为最不会出事的那一个，而且他踏出第一步的理由要让人同情（为了女儿、为了面子、为了不麻烦人）。
- **两三样一直出现的东西**：一样物件、一句话、一个数字。每次出现意思都变一点，最后一集反过来。例：「吃饱了吗」第一集是骗子问她，中间是她问女儿、女儿回「忙」，最后一集是女儿先问她。

故事里有钱、日期、人数这些数字的，在系列表里列一张时间线，每集照着写，十集的数字才对得上。

## 2. 十集怎么排

| 集 | 做什么 | 观众得到什么 |
|---|---|---|
| 1 | 把人压到最低，或让他踏出回不了头的第一步。露出他手上有的一样东西 | 一个想知道答案的问题 |
| 2 | 第一集的后果到了。不能重演第一集 | 事情比他想的严重 |
| 3 | 他第一次还手，小小赢一下 | 证明这个系列会给回报 |
| 4–6 | 对手加码，一集比一集难。每两三集放一条新线索 | 一次次以为要成了 |
| 7 | 一次看得见的赢 | 追到这里的奖励 |
| 8–9 | 赢的代价来了，比之前更糟 | 最想知道结局的时候 |
| 10 | 收尾，回到第一集的那个画面或那句话 | 一个完整的结束 |

- 八集就把 4–6 压成两集。
- **最迟第 3 集要让他赢一次。** 连着三集只有倒霉，观众就走了。
- **最后一集要收，不要再吊。** 长剧的做法是永远不收，短系列反过来：收得干净，观众才会去看你的下一个系列。
- 回报的节奏：每一集有一个落地的小结果，第 3、第 7 集有看得见的赢，最后一集最大。一次比一次大。

## 3. 一集里面怎么走

以 45 秒一集为例：

| 位置 | 做什么 |
|---|---|
| 0–3 秒 | 上一集钩子的后果，直接是画面。不回顾、不旁白 |
| 3–12 秒 | 这一集他要做的一件事，谁在挡 |
| 12–28 秒 | 他做了一个选择，对方还手 |
| 28–38 秒 | 一个落地的结果：拿到了、失败了、知道了一件事 |
| 38–45 秒 | 从这个结果长出来的新麻烦，停在这里 |

- **一集只做一件事**，能用一个动词讲完：追、躲、查、求、骗回去。
- **一集结束时，要有一件事回不去了。** 钱转出去了、话讲出口了、被人看到了。只是谈了一场、吵了一架，局面没有变，那不算一集，并进别的集。分集是照这种变化来切，不是照字数或时间平均切。
- **先给结果，再留钩子。** 整集只有「马上就要揭晓」，没有任何一件事落地，观众会觉得被耍。
- 时长预算照 `structure.md` 第 9 节，一样是每秒 4 个字。

## 4. 集尾钩子十三种

钩子要从这一集的结果里长出来，不是另外贴一件事上去。全系列不要十集都用同一种。

| 钩子 | 是什么 | 例 |
|---|---|---|
| 证据露一半 | 看到了，但关键那一块被挡住 | 转账截图放大，收款人的名字被拇指挡着 |
| 将赢未赢 | 差一步就成，被截住。最强的一种 | 她按下报警电话，对方先叫出她的全名 |
| 身份露一角 | 认出一点点 | 「客服」的头像，和表哥朋友圈里是同一张图 |
| 来人、来电 | 被打断 | 银行柜员刚要开口，「老师」的电话进来 |
| 站队 | 最亲的人站到另一边 | 妈妈讲：「我信他，不信你。」 |
| 已经开始了 | 坏事在倒数 | 屏幕上：转账处理中，59 秒 |
| 一定要现在选 | 两样只能拿一样 | 撤回要验证码，骗子也在催同一个验证码 |
| 全部人知道了 | 事情公开 | 家族群里有人转发了她的借条 |
| 对手升级 | 你以为甩掉了 | 拉黑之后，一个新号码传来她家门口的照片 |
| 小赢带出大麻烦 | 刚松一口气 | 追回五百块，才发现名下多了一笔贷款 |
| 代价到了 | 前几集做的事回来了 | 昨天点的那个链接，今早薪水户口被冻结 |
| 旧东西新看法 | 同一样证据，再看一次不一样 | 那张「警局公文」，落款的日期是明年 |
| 他自己选错 | 有人给他一个讲真话的机会，他没有拿 | 朋友问「谁打来？」她把手机压在胸口：「没有，打错的。」 |

每一集写完，钩子要答得出三样，缺一样就是弱的：

1. **观众在等什么**：写成一句清楚的「下一集的问题」。
2. **他为什么在意**：等不到会怎样，谁会受伤、会丢掉什么。
3. **下一集第一个动作是什么**：答得出，表示这个钩子真的接得下去；答不出，多半是硬加的。

**除了集尾钩子，每一集结束时还要有至少两条没解开的线**（最后两集不用，那时候是在收线）。 集尾钩子下一集就兑现了，留住人的是那些更长的问题：老师到底是谁、钱拿不拿得回来、妈妈信不信她。十集的系列，最长的那条线从第一集撑到最后一集，另外一两条撑三四集。

## 5. 开头怎么接上一集

- 第一个画面就是上一集钩子的后果。上一集停在「59 秒」，这一集开场是「0 秒，转出成功」。
- 从第 2 集起，「开场是上一集的后果」比「第一句是冲突台词」优先。两样能用同一句做到最好（上一集她答应不讲，这一集第一句是电话里问「门锁了吗？」）。
- 不让人物复述上一集发生的事。
- 下一集不能当上一集没发生过。上一集做的决定、付的代价，这一集都还在。
- 上一集的钩子，这一集要马上兑现一点，不能再拖一集。

每一集也要让第一次看到的人看得懂：开场十秒内，从画面就看得出谁在怕什么。靠的是把人放进压力里，不是靠解释。

## 6. 哪些东西不能一集还完

- **证据拆四步**：从哪里来、是真是假、给谁看、拿出来之后的反扑。一步一集。
- **身份和真相分级放**：先露一角，再认出是谁，最后才知道为什么。
- **小对手不要太早打完**，留到后面还能用。
- **对手不能太弱**：第一次交手是对手占上风，或至少全身而退。主角真正赢之前，两边至少来回三次。对手一出场就输，后面就没有人可以担心了。
- **代价不能自动消失**：这一集丢的钱、破的关系，下一集还是丢着、破着。
- **埋了就要收**：前面出现过的东西，最后一集之前要用上。

## 7. 产品怎么植入

系列里的产品不是答案，是**主角一直在用的那样工具**，或两个人之间的**信物**。

- **第一集就出现，但没有人讲它好。** 它只是他手上的一样东西。
- **每一集它帮上一个小忙**，而且是这一集的故事需要的。拿掉它，这一集走不下去才对。
- **一集最多出现一次、三秒以内。** 不给特写，不念品牌名。
- **卖点只讲一次**，放在第 7 集那次赢，或最后一集。由一个本来就会讲这种话的人讲。
- **品牌名和购买方式放片尾的后制字卡**，每集都可以有，不进戏里。
- 整个系列还是只讲**一个**卖点。

系列表里加一栏「产品在这一集做什么」。有一集填不出来就空着，不要硬塞。空三集以上，表示这个产品和这个故事对不上，换故事。

### 没有产品的系列（公益、涨粉）

像防骗、安全、理财常识这类，没有东西要卖。把「要观众记住的那一件事」当成产品，规矩这样换：

| 有产品时 | 没有产品时 |
|---|---|
| 一个卖点，全系列只讲一次 | 全系列合起来是一句话；每一集各有一件小的要记住的事 |
| 产品是主角的工具，一集出现一次 | 那件事就是这一集的戏：主角做错了，或做对了，后果演给人看 |
| 品牌名放片尾字卡 | 那件事用一行字放在片尾字卡，每集一行 |
| 换产品测试 | 换一件要记住的事，这一集还讲得下去吗？讲得下去就是没演到 |
| 为什么链从卖点出发 | 从「人为什么明知道还是会做错」出发 |

片尾那一行字不算讲破。不讲破管的是戏里的人不替观众讲答案；戏结束之后的字卡，是给只看到这一集的人带走一样东西。但戏里的旁白和台词还是不能讲「后来我才知道……」这种话。

教人防范的内容要守两条：

- **拍受害的人看到什么、哪一刻该停**，不要把坏人的整套话术、步骤完整演一遍，不然变成教人做。
- **求助的号码、流程、法律后果不要凭印象写。** 写 `【请确认】`，请用户照官方最新的资料核对。不写「钱一定追得回」这种结局。

## 8. 追更失败的病

| 病 | 样子 |
|---|---|
| 假钩子 | 故意藏一句话不讲、镜头切走；或结尾只是动作做到一半停住 |
| 全部推到下一集 | 这一集什么都没落地 |
| 第 2 集重演第 1 集 | 同样的人、同样的吵法，只是换了地方 |
| 一直惨 | 到第 3 集结束还没有赢过一次 |
| 一直赢 | 没有代价，观众不担心 |
| 下一集重来 | 上一集的决定和代价不见了 |
| 临时来一个人 | 之前没出现过的人踹门进来解决问题 |
| 升级只是更大声 | 吵得更凶，但局面没有变 |
| 对手变笨 | 为了让主角赢，对手突然犯很蠢的错 |
| 最后一集还在吊 | 没有收尾 |

## 9. 交付：系列表和第一集

先交系列表，用户点头了才写第一集。一次只写一集；用户要一口气写完，也是一集写完、过完自查，再写下一集。

```markdown
# 《系列名》系列表 v1

__ 集 · 每集约 __ 秒 · 9:16 竖屏
一个人要什么：____ ｜ 谁在挡：____
观众每一集回来看什么：____
最后一集停在哪里：____
产品：____ ｜ 卖点（只有一个）：____ ｜ 它在戏里是：____（工具 / 信物）

## 人物（全系列固定）
| 人物 | 是谁 | 长相和衣服一句话 | 讲哪一种话 |

## 场景（重复用）
1. …

## 十集
| 集 | 这一集他做什么（一个动词） | 回不去的那件事 | 集尾钩子（哪一种） | 下一集的问题 | 还没解开的线 | 产品在这一集做什么（没有产品就写：这一集要观众记住的一件事） |
|---|---|---|---|---|---|---|
| 1 | | | | | | |

## 一直出现的东西
- 物件 / 一句话 / 一个数字：第 _ 集第一次出现，最后一集怎么反过来

## 数字时间线（有钱、日期、人数才要）
| 第几集 | 发生什么 | 数字 | 累计 |

## 不能一集还完的
- 证据：第 _ 集拿到，第 _ 集知道真假，第 _ 集公开，第 _ 集反扑
- 身份：第 _ 集露一角，第 _ 集认出，第 _ 集知道为什么

## 请你确认
- …
```

文件这样存：`<当前文件夹>/剧情/<系列名>/系列表.md`，每一集是 `第1集-剧本.md`、`第2集-剧本.md`。

每一集的剧本照 `structure.md` 第 10 节的格式，开头多写两行：

```
接上一集：____（上一集钩子的后果，就是这一集第一个画面）
这一集的钩子：____ → 下一集的问题：____
```
