## 0. 主路：反推法

只有一个巧妙的概念（「武功要四十九天，冰箱几分钟」「一个词两个意思」），观众只会点头，不会笑。我们做过、观众真的笑的片（`冰箱篇`、《Kopi 家族》、thai-ad 的学员广告）都是这样反推出来的：

1. **把卖点推到最极端，变成一个人身上的后果。** 不是「冰箱很冷」，是「有人在冰箱里冻死了」；不是「车翻新得好」，是「贼在一排 Mercedes 里偷了一辆 Saga」；不是「屋卖得快」，是「他进去冲个凉，出来屋已经卖掉了」。
2. **让这个后果连累别人，或被别人误会。** 老公以为老婆偷人，翻遍整间屋；邻居看到 23 岁的人开新车，报警说他是 Ah Long；屋主裹着毛巾被关在门外。
3. **一路问「为什么会这样」，退到一个看不出卖什么的开场。** 开场要是一个人正在出大事：鬼搭上肩膀、特警破门、豪门逼媳妇生继承人。观众一路猜「这是卖什么的」，猜不到。
4. **最后，产品是唯一讲得通的答案。**

每一步都要讲得通（第 3 节为什么链）。同一个卖点，在第 1 步换一个后果，就是一支新广告。

### 好笑的五个来源

一个点子至少要有前三样：

| 来源 | 样子 | 例子 |
|---|---|---|
| **① 观众猜不到卖什么** | 开场 10 秒看不出是哪一类产品 | 鬼片开场，到第 27 秒才知道是冰箱 |
| **② 赌的东西很大，答案很小** | 有人可能丢命、离婚、绝后、被抓、没了屋、丢大脸；答案只是一样家电、一杯饮料 | 豪门要断绝关系，生出来是一杯 Cham |
| **③ 人和人之间有一件事** | 偷情、捉奸、欠钱、婆媳、装有钱、瞒着老婆、抢遗产、被邻居误会。观众一秒就懂，马上有立场 | 情夫躲冰箱，老公在外面捉奸 |
| **④ 错的重点** | 天大的事面前，角色在意一件小事或完全错的事 | 两只鬼讲自己怎么死的，瘦鬼在意的是「在马来西亚也可以冻死？」 |
| **⑤ 第二下** | 第一下揭晓产品，第二下揭晓人和人的关系或身份，观众回头重看一次 | 「你做么不开冰箱！」……「等下，你在我家做什么？」 |

还有一条底线：**不用背景知识。** 要先懂武侠、典故、某部剧才看得懂的，问一句「一个没读过华文的马来人、一个十八岁的年轻人看得懂吗」，看不懂就不拿它当主笑点。

这五样都要靠**认真演**：鬼片拍得像真鬼片，捉奸拍得像惊悚片，戏里没有人知道自己在搞笑。

## 1. 产品和故事的五种关系

| 关系 | 样子 | 用不用 |
|---|---|---|
| **答案** | 观众一路在问「为什么」，产品一出来全部讲通 | 首选 |
| **谜面** | 产品从头到尾没出现；它要解决的那个问题被演成一个谜，最后一句双关接上 | 首选，适合讲感觉的产品（护肤、保健、床褥） |
| **万能道具** | 一个危机用一个功能解掉，连续三次 | 可以，适合功能多的产品；产品会早出场，要靠一个比一个离谱的危机撑住 |
| **信物** | 产品从头就在戏里，但只是一样道具（他每年都递给她同一盒牛奶），没有人讲它好在哪里；卖点压到七八成才讲 | 可以，适合产品本来就跟故事有字面关联的时候（牛郎和牛奶）。见第 2 节末尾 |
| **戏里推销** | 角色在戏里把卖点讲一遍 | 不用。观众一听到就滑走 |
| **硬接口播** | 故事讲到一半，停下来卖东西，再回去讲 | 不用。故事和产品没有关系，换什么产品都一样 |

下面的十种机制，写出来的都是「答案」或「谜面」。

## 2. 十种答案机制（卡住时用）

第 0 节的反推法走不出来，才从这里换一种。这里的点子写出来，一样要过第 3 节的五道筛子，尤其是「猜不到卖什么」和「赌得够大」：双关、没用的本事这几种最容易只剩一个聪明的概念。

### ① 往回问（逆向演绎）

把卖点夸张成一个荒谬的结果，问「什么情况下会这样」，挑最离谱的，一路问为什么，问到一个跟产品无关的世界。那个世界就是开场。

- 卖点：冷气很冷 → 冷到进了屋的人不肯出来 → 谁会赖在别人家？新年来拜年的客人 → 坐了多久？年初一到现在 → 屋主怎么办？报警 → 警察进去劝，也不出来 → 开场：警车包围一间排屋，谈判专家喊话「你们已经进去两百八十七天了」。

### ② 一词两义

找一个词，它在产品这边是一个意思，在狗血剧那边是另一个意思。前半段观众听的是狗血的意思，揭晓那一秒变回字面。

- 「偷吃」：老公带人去酒店捉奸，掀开被，枕头上是一粒榴莲。好吃到要背着老公偷偷吃。
- 「粘人」：女生骂男友粘人。「这不是粘人，是服帖。」（持妆的气垫）
- 找词的方法：把卖点写成一句大白话，把里面每个动词、形容词拿出来，问「这个词在感情、家庭、鬼片、警匪片里是什么意思」。

### ③ 听错

一个人在讲平常的话，旁边的第三者用另一种语言听成别的意思，而且照着办了。片里不解释。大马人平时掺着几种语言讲话，这种词特别多。

- Uncle 在茶室喊「老板，Kaya！」（要面包），树下神龛里的拿督公听到的是马来语的 kaya（有钱），一块金条掉在桌上。
- 要点：讲话的人做的是每天都会做的事，不能为了梗硬讲那句话。听错的那一方只是很认真地照字面办事。

### ④ 两样合成一样

产品是「A 加 B」的结合（二合一、混合口味、多功能），就把 A 和 B 写成两个誓不两立的家族、门派、亲家。孩子生出来，是第三样。

- 洗衣液豪门逼媳妇生一个纯正的继承人，生出来是洗衣凝珠。
- 观众会猜，而且猜得到。猜中的人会去留言，这是好事。

### ⑤ 俗话成真

大家嘴上都讲、心里半信的那些事，在片里是真的，而且有人把它当成正经大事来办。

- 找料：一带伞就不下雨、刚拖完地就有人踩、一讲他他就到、一排队隔壁那条就比较快、一冲凉电话就响。
- 从卖点往回对：产品解决的是哪一种「每次都这样」的倒霉事？把那件倒霉事升级成全国级的现象。

### ⑥ 放弃一样，垮一级

角色为了省钱（或嫌麻烦），一样一样地放弃。每放弃一样，画面上立刻垮一级。最后一句：其实一样东西就够了。

- 收银台钱不够。「护发素不要了」→ 头发当场变毛躁。「洗发水也不要了」→ 当场秃掉。「那就买二合一。」
- 适合短梗。垮的东西要在画面上一眼看得出来。

### ⑦ 没用的本事，刚好有用

给主角一个很小、很没用的超能力或怪习惯，全片都在讲它多没用。最后发现产品做的就是同一件事，而且做得更好。

- 「我能看见未来，但只有 1.5 秒。」催泪片拍到车祸前一刻，车自己刹住了（自动刹车）。
- 这一种可以不搞笑，走感人路线。

### ⑧ 只有他没事

一件所有人都躲不过的坏事，只有一个人没事。全片都在猜为什么，每个人有一套讲法。答案是他用了产品。

- 女鬼扫过全村，只有老林坐在门口喝 kopi，女鬼到他面前一米就干呕后退。道士查不出，阿窿也进不去。村长：「你到底擦了什么？」（驱蚊水）
- 让片里的人替观众乱猜，留言区就会跟着猜。

### ⑨ 大家等的答案，是一样很小的东西

借一个观众本来就在等答案的局面：身份揭晓、遗嘱宣读、手提箱打开、「他到底是谁」。或者借一个典故里现成的疑问。答案出来，是一样很日常的东西。

- 五年前被老爷赶出门的年轻人，留下一句「五年后我一定回来」。五年后的雨夜他站在门口，全家吓到要跪。他抬头看了一眼天花板：「老板，五年到了，我来洗冷气。」
- 诸葛亮前两次为什么不见刘备？他在等快递。
- 要点：前面的戏要演到观众真的相信答案很大，落差才够。

### ⑩ 问题演成谜（产品不出场）

不拍产品，拍产品要解决的那个问题，把它演成一件怪事。全片在查原因，最后一句话双关，一个镜头带过产品。

- 雕塑家的作品一夜一夜变老、变垮，查监控、上新闻，最后发现是他自己磨掉了棱角。结尾一句「让棱角又回来了」，才看到面霜。
- 适合护肤、保健、睡眠、教育这类讲不出一个画面的产品。全片可以一点都不好笑。

### 例外：产品当信物，早出现、晚讲卖点

有些产品跟某个故事天生有字面关联（牛郎和牛奶、月老和红线、灶神和厨具）。这时候产品可以一开场就出现，当成两个人之间的信物，反复出现但没有人讲它的好处。规矩有三条：

- 七八成之前，它只是一样东西。没有卖点、没有品牌特写。
- 卖点由一个职业上本来就会讲这些话的人讲（店员、师傅），讲完让对方吐槽一句「你做么酱专业」，把广告味消掉。
- 最后一句用一个词同时讲产品和感情，配一个具体的习惯画面（她每天多留一盒），不喊人去买。

没有这层字面关联就不要用这一种。硬套上去，产品换成什么都行，就过不了下面的换产品测试。

## 3. 五道筛子

每个点子都要过，过不了就丢掉，不要修修补补：

1. **换产品测试。** 把产品换成同一个档次的别的东西（冷气换成沙发、榴莲换成蛋糕），故事还讲得下去吗？讲得下去，产品就不是答案，只是贴上去的。换成别牌的同类产品还讲得下去，是正常的：急冻、容量大是整个品类都有的好处。品牌的分别靠产品段的一个具体数字或一个品牌专属的画面，不靠剧情。
2. **为什么链。** 从开场到产品，把每一步的「为什么」写出来，至少四步。每一步问三个问题：
   - 真的会有人这样做吗？（没有华人会跪着求「我要 kaya」，所以那一版不成立。）
   - 他为什么不干脆……？（冷气冷到冻死人：人明明可以走出房间。答不出就是洞。）
   - 这一步是因为上一步才发生的吗？（如果只是「接着又发生了一件好笑的事」，那是一串小品，不是故事。）
3. **一句话。** 能不能用一句会被人转述的话讲完？「满停车场 Mercedes，他偷了一辆 Saga。」讲不成一句话，就是还没想清楚。
4. **猜不到卖什么。** 只看开场 10 秒（画面加台词），一个没看过简介的人猜得到是哪一类产品吗？猜得到就是露底：开场出现「冰」「冻」「寒」就会让人想到冰箱，出现泡泡、脏衣服就会想到洗衣用品。把露底的东西挪到后面，挪不走就丢。
5. **赌得够大。** 戏里有没有人可能丢掉命、婚姻、继承权、屋、钱、自由或面子？赌的只是一碗水、一包虾、一件衬衫，答案再巧也没人在乎。

## 4. 点子的八种死法

| 死法 | 样子 | 例 |
|---|---|---|
| 只有概念，没有人 | 一个聪明的对比或双关，没有人和人之间的事，赌的东西很小 | 武功冻一碗水要四十九天，冰箱几分钟。观众点头，不会笑 |
| 开场就露底 | 开场的道具、台词让人马上想到产品那一类 | 开场就是一碗要结冰的水 → 观众猜到冰箱 |
| 要背景知识 | 先懂武侠、典故、某部剧才笑得出 | 「寒冰掌」：马来观众和年轻人不知道是什么 |
| 先想笑点，再硬接产品 | 前面大半段跟产品没有关系 | 绑匪在塞车里找 parking，最后接冷气。换什么产品都行 |
| 第一句就露底 | 一开口观众就知道卖哪一类东西 | 第一句出现「秘方」，观众就知道是卖吃的 |
| 靠一句台词补洞 | 有一步讲不通，用一句解释带过 | 「绑匪的货仓刚好装了很好的冷气」 |
| 堆类型 | 霸总、重生、战神、萌宝全部都要 | 观众两秒认不出这是什么戏 |
| 只有设定，没有现场 | 「一个女婿其实很厉害」 | 要写成：他在什么场合、被谁、当着谁的面、拿走了什么 |

## 5. 卡住的时候

- 换一种机制，不要在同一种里换细节。
- 先找字面关联：产品的名字、材料、用法里，有没有一个字跟某个神话、典故、俗话、类型片撞在一起（牛奶和牛郎、滚水和「滚」）。有的话，壳就从那里来。
- 把卖点再写具体一点。「地点方便」想不出东西，「走路 5 分钟到 MRT」想得出。
- 问用户要一个真的细节：客人最常抱怨的一句话、一个真的数字、一件真的发生过的事。
- 从这门生意的「每次都这样」下手：客人每次都会问什么、每次都会做错什么、每次都后悔什么。

## 6. 借爆款的骨架

真的被很多人看过、笑过的片，骨架可以借：借它的机制、壳、反转在哪里、产品在几成出现。人物、台词、桥段一律换成自己的（`SKILL.md`「合规」最后两条）。下面是我们拆过、做过的：

| 片 | 骨架（一句话） | 好笑在哪 | 换成别的产品怎么借 |
|---|---|---|---|
| 101AI《洗衣液家族》→ 太KawLah《Kopi 家族》 | 豪门逼媳妇生纯种继承人，全家紧张到产房，生出来是两边合成的第三样 | 豪门狗血认真演；赌的是继承权；答案是一杯 Cham | 产品是「A 加 B」的（二合一、混合口味、多功能）：A、B 写成两个门派 |
| 101AI《悬疑厨房》→ 太KawLah《冰箱篇》 | 两只鬼在屋里第一次见面，聊怎么死的；一个躲在产品里死了，一个在外面气死了；最后发现彼此是老公和情夫 | 鬼片开场看不出卖什么；赌的是命；「你做么不开冰箱」是错的重点；身份揭晓是第二下 | 产品够大、够密封、够冷、够静：变成情夫的藏身处，后果推到死 |
| thai-ad《偷 Saga》 | 劫案片：贼在一排豪车里偏偏偷了一辆旧车，被审问时才知道它是翻新的 | 劫案片认真演；连贼都看错 | 「旧的像新的」「便宜的像贵的」：让一个专业的人看走眼 |
| thai-ad《特警破门》 | 警匪片：特警包围一间屋，抓一个刚出来做工就开新车的年轻人 | 赌的是自由；邻居误会；答案是首期低 | 「太容易得到」的卖点：让旁人以为他做了坏事 |
| thai-ad《毛巾男》 | 一个男人裹着毛巾站在路边；他进去冲个凉，屋就卖掉了 | 第一个画面就是怪事；答案很小 | 「太快」的卖点：快到当事人来不及做完一件私事 |

借之前问自己：这支片好笑，是靠上面五个来源里的哪几样？换了产品之后，那几样还在吗？
