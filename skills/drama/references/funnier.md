# 不好笑：先诊断，再补一样

用户说「不好笑」「不够好笑」「加个反转」「再无厘头一点」时读这一份。

不好笑几乎从来不是因为「不够无厘头」，而是少了某一样东西。乱加料只会让剧本更长、更乱。先找出少了哪一样，再补那一样。

1. 先诊断：五个来源打勾
2. 七个工具：缺什么补什么

## 1. 先诊断：五个来源打勾

先不要改。剧本里还没有「白话文」一节的，先替原版写一段，后面改之前和改之后才有得比。然后拿剧本对着 `ideas.md` 第 0 节的五个好笑来源，一样一样打勾，每一格都要指出是哪一行：

| 来源 | 问 | 常见的毛病 |
|---|---|---|
| 猜不到卖什么 | 只看开场 10 秒，猜得到是哪一类产品吗？ | 开场就出现产品那一类的东西（冰、泡泡、脏衣服） |
| 赌得大，答案小 | 有人会丢掉命、婚姻、继承权、屋、钱、自由或面子吗？看得见吗？ | 赌注只讲出口，画面上看不到（「我要离婚！」不如律师拿着离婚书站在门口） |
| 人和人的事 | 有偷情、欠钱、婆媳、被误会吗？ | 只有一个概念，没有人在乎谁 |
| 错的重点 | 有人在天大的事面前在意一件小事吗？ | 每个人都在讲正事 |
| 第二下 | 产品揭晓之后，还有再来一下吗？观众看得出来吗？ | 没有第二下；或者太隐晦，要观众记得前面一个小细节才懂 |

另外查两样：

- **笑点是不是太早用完？** 一个笑点只出现一次，后面就没东西了。
- **最后一下是动作，还是要观众自己想？** 要观众自己推理的结尾，多数人会错过。

给用户的诊断要写成：哪一样缺了、在哪一行、为什么。只讲「不够好笑」不算诊断。

**诊断出来是点子的问题**（猜得到卖什么、没有人和人的事、要背景知识），补料救不了，老实告诉用户，回第 2 步换点子。补料只修得好写法的问题。

## 2. 七个工具：缺什么补什么

| 缺的 | 用哪个工具 |
|---|---|
| 第二下 | ① 加第二下 |
| 赌得大 | ② 把赌注加大，而且放到画面上 |
| 错的重点 | ③ 加错的重点 |
| 笑点太早用完 | ④ 三次升级 |
| 整体太平、太像广告 | ⑤ 换一个更严肃的壳 |
| 笑点落不了地 | ⑥ 加一个旁观者的反应 |
| 太长、讲太多 | ⑦ 删 |

### ① 加第二下（反转）

产品揭晓之后，再揭晓一件人和人之间的事：身份、关系、谁骗了谁、谁一直知道。

- 要让观众**回头把前面重新看一次**：前面看起来普通的人或动作，原来另有意思。
- 前面要先铺：第二下揭晓的那个人，前面要有一两个画面让人事后觉得「难怪」（婆婆面不改色地叠衣服）。
- 用一个看得见的动作或一句短话落地（眨一下眼、「下次自己洗」），不要靠观众记细节推理。
- 回扣开场那句话（「好。现在讲，她是谁？」）是收尾，不算第二下：它没有揭晓新的事。

### ② 把赌注加大，而且放到画面上

从一件小事加到命、婚姻、继承权、屋、钱、自由或面子。加大之后，要有一样**看得见的东西**代表它：离婚书、遗嘱、手铐、整个家族围观、直播的手机。输的时候，那样东西被收走、撕掉、关掉。

### ③ 加错的重点

找一个配角，问：这个人此刻最应该在意什么？让他在意别的。最好是他平常的身份会在意的小事（婆婆在意地板、老板在意电费、医生在意排队号码）。

### ④ 三次升级

同一件事发生三次，一次比一次离谱。第三次是最大的，或者第三次之后翻转。

- 三次最好同时把卖点演三次（衬衫、枕头套、车座套都被洗白），等于用画面讲三次「什么渍都洗得掉」，比旁白讲一次有力。
- 每一次升级都要讲得通（第 4 节）。
- 短梗时间少：每一次升级用一个画面、两秒左右，不要每次都配台词。

### ⑤ 换一个更严肃的壳

用 `genres.md` 里更正经的拍法重写开场：警匪片、鬼片、新闻直播、法庭、豪门。演员演得越认真越好笑。

### ⑥ 加一个旁观者的反应

笑点之后，加一个旁边的人的反应：不讲话，只是看、愣住、慢慢转头。笑点要靠别人的反应才落地，观众会跟着那个人一起反应。

### ⑦ 删

不好笑很多时候只是太长。删这几种：

- 解释笑点的、讲破的（`SKILL.md` 第 5 节第二关）
- 同一个意思讲两次的
- 画面已经演了、台词又讲一次的

删完往往比加料更有效。

## 3. 怎么改：一次一样，改完比较

1. 把诊断给用户，建议先用哪一两个工具，讲一句为什么。用户点头再改。
2. **一次只用一个工具**（用户要一次改几样也可以，但对照表要分开写每一样改了哪里）。
3. 每改一版，交三样：
   - 改了哪几行：原来是什么，现在是什么
   - 改之前和改之后，**各用白话文讲一次**（`SKILL.md` 第 6 节的写法），让用户自己比哪一版好笑
   - 重跑 `check_script.py`。加料常常会超字数、超秒数（短梗最多 33 秒、80 字），超了就删别的地方，先删标了【可删】的行，不要把秒数改小
4. 存成新的版本：`剧本-v2.md`、`剧本-v3.md`，旧版不要覆盖，用户要拿来比较。
5. **三个工具都试过还不好笑，就是点子的问题。** 不要再修，回第 2 步换一个点子。

## 4. 无厘头的底线

无厘头不是乱来。观众笑，是因为离谱但讲得通。只要有一步他会问「怎么可能」，就出戏了。

每加一样离谱的东西，都问一次：「他为什么不干脆……？」剧本里要答得出来，最好是一个画面或一句很短的话（大哥问「你没拍照咩？」；车座套挂着车钥匙，一看就知道是车上的）。答不出来的离谱，删掉。

加料也要守合规（`SKILL.md`「合规」）：第二下如果让品牌变成坏事的帮凶（帮人洗掉偷情证据），在「我担心的一点」讲明，并给一个折中的收法（最后被拍到、被抓到），让观众站在对的那一边。

## 5. 例子：《证物》v1 → v2

KAW 洗衣机，卖点「什么渍都洗得掉」，30 秒短梗。

**v1 白话文**：老婆阿芬带两个哥哥上门捉奸，证据是一件有口红印的衬衫。婆婆抱着洗好的衣服出来，只顾着叫大家脱鞋。衬衫领口是雪白的，证据被洗掉了。阿芬气到补口红，大哥看着她的嘴：领口那个口红印，可能是她自己的。

**诊断**

| 来源 | v1 | 问题 |
|---|---|---|
| 猜不到卖什么 | 捉奸开场 | 有 |
| 赌得大 | 婚姻 | 只是吵一架，画面上看不到 |
| 人和人的事 | 偷情、婆媳 | 有 |
| 错的重点 | 婆婆在意地板 | 有，一句 |
| 第二下 | 口红是她自己的 | 太隐晦，要观众记得她开场涂什么颜色 |

另外：证据只有一样，翻一次就没了，笑点太早用完。

**用了三个工具**

- ④ 三次升级：衬衫、枕头套、车座套，一样一样被洗白。越洗越干净，越可疑，也等于把卖点演了三次。
- ② 赌注加大、放到画面上：阿芬带了律师和离婚书，输了律师当场把离婚书收回去。
- ① 换第二下：门一关，婆婆把衬衫塞回儿子手里，眨眼：「下次自己洗。」原来她是帮凶。前面她面不改色地叠衣服、说「脏就洗咯」，就是铺垫。最后一个画面，阿芬在窗外录影：观众站在阿芬那边，品牌不变成帮凶。

**v2 白话文**：阿芬怀疑老公偷吃，带了两个哥哥，还带了律师和离婚书，冲回家拿证据。婆婆抱着洗好的衣服出来，只顾着叫大家脱鞋。阿芬一样一样翻：衬衫雪白，枕头套雪白，连车座套都雪白。大哥觉得不对劲，婆婆只说「脏就洗咯」。证据全没了，律师收起离婚书，一行人走掉。门一关，婆婆把衬衫塞回儿子手里，眨眨眼：「下次自己洗。」可是阿芬根本没走，她在窗外全部录了下来。

**结果**：笑点从两个变成四个，台词从 49 字变成 42 字。加料不一定要加台词，多数是加画面。
